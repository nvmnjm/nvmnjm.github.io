# Najam Gohar

Personal academic portfolio, published at https://nvmnjm.github.io/.

- `index.html` is the whole site (home menu, pages, publications, abstracts, news).
- `assets/` holds the portrait.
- `build/content.json` holds all content; `build/pubmed_ids.json` maps DOIs to PubMed and PMC ids.

To update: edit `build/content.json`, run `python build/build_site.py`, then commit and push `index.html`.
